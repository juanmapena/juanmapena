## 🤖 QA, Automatización e IA

Actualmente trabajo como **QA Analyst**, participando en procesos de aseguramiento de calidad dentro de equipos ágiles.

🔍 Experiencia práctica en:
- 🧪 Testing funcional, regresivo y exploratorio
- 🧾 Diseño y ejecución de casos de prueba
- 🔌 Testing de APIs (Postman / Hoppscotch)
- 🗄️ Validación de datos en bases de datos
- 📊 Seguimiento de issues y flujos críticos (Jira)

🤖 En paralelo, estoy explorando **automatización de testing asistida por IA**, utilizando herramientas como **Stagehand (E2E)** para:
- Optimizar flujos de prueba
- Reducir esfuerzo manual repetitivo
- Analizar comportamientos y resultados de testing

Mi objetivo es **evolucionar el QA tradicional hacia un QA moderno**, combinando testing, automatización, desarrollo e inteligencia artificial.

🔎 Me destaco por:

- 🧩 Desarrollo de interfaces modulares con componentes reutilizables (HTML, CSS, React.js)
- 🔌 Integración de APIs RESTful y manejo dinámico del DOM
- 📱 Diseño responsive y mobile-first enfocado en experiencia de usuario (UX/UI)
- ♿ Aplicación de buenas prácticas de accesibilidad y compatibilidad cross-browser
- 🧠 Capacidad de análisis y lógica estructurada para resolver desafíos técnicos
- ⚙️ Fluidez en herramientas de control de versiones (Git, GitHub) y automatización básica (npm, scripts)
- 🧪 Testing manual en navegadores y dispositivos
- 🤝 Trabajo colaborativo en equipos ágiles y proactividad para asumir nuevos desafíos
- 🚀 Compromiso con la mejora continua y aprendizaje constante (Node.js, Java, Python, Next.js)
- ☕ Construcción de lógica robusta en Java aplicando POO Avanzada y metodologías Test Driven Development (TDD) con JUnit.
